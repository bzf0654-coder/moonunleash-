# MoonUnleash：MoonBit 原生功能开关 SDK

**方向：**工具库 / 成熟生态适配　 **阶段：**可运行开发预览，申请立项而非完整验收

**申请人 / GitHub ID：**待确认　 **公开仓库：**待授权发布　 **许可证：**Apache-2.0

### 问题与用户

MoonBit 服务融入多语言系统时，需要复用既有 Unleash 发布规则，进行稳定灰度、用户分流和变体实验。项目提供可复用的本地评估库，避免每次判定访问远端或部署其他语言中间服务；不再造管理后台，不以外部 SDK 代替 MoonBit 内核。

### 技术路线与实质工作

参考官方规范与成熟 SDK，在 MoonBit 实现配置校验、MurmurHash3 分桶、策略/约束组合、全局变体和私有快照；异步适配负责注册、轮询及 ETag 更新。难点在跨语言分桶一致性、功能/变体状态区分，以及失败更新、陈旧状态和取消的可靠语义，而非接口包装。

### 已有原型与证据

已有源码、[README](<../README.md>)、离线示例、在线入口和真实开发历史。支持基础/用户策略、legacy/flexible 灰度、基本字符串/数值约束、全局变体及自定义 stickiness。固定官方规范共 22 组 294 条，当前选定 12 组 **93 条通过、201 条明确未执行**；不称完整兼容。

wasm 32 项测试通过，wasm-gc/JS 纯核心各 24 项通过。实际回环 HTTP 验证了 304、坏配置、503、重定向拒绝和响应限额；服务端为可控模拟，**尚不是真实 Unleash 互通验收**。

### 本期交付、风险与边界

以可复用 SDK、逐用例报告、故障演示、许可和开发说明交付；继续补参考 SDK 差分、真实服务器互通和 native 验证，再扩大兼容范围。当前不含管理后台、metrics、磁盘缓存、增量流、OpenFeature 或性能承诺。未知语义会拒绝整份新快照，保留旧状态；本机缺少 MSVC，native 未通过验证；CI 仅已配置，实验性异步 API 存在版本风险。

AI 辅助实现、文档查询与测试编排；参赛者必须理解并负责结果。保留来源许可、原始预期值和真实提交，不以生成资料凑代码量。

**复现：**`moon test --target wasm --deny-warn`；`moon run cmd/main --target wasm-gc`；`node tools/http-smoke.mjs`。
